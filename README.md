# 🌌 Stellar Burgers — Автоматизация тестирования 🌌

Автоматизация тестирования веб-приложения **Stellar Burgers** с использованием **Selenium**, **pytest** и **Allure**.
Проект покрывает как **UI**, так и **API**, обеспечивая надежную проверку всех критических сценариев работы приложения.

---

## 🚀 Основные возможности

### UI тесты:

* Переходы по клику на: **Конструктор**, **Лента заказов**, **Личный кабинет**
* Проверка **модальных окон ингредиентов** (открытие/закрытие)
* Drag & Drop ингредиентов в корзину конструктора
* Проверка увеличения **счетчиков ингредиентов**
* Статистика заказов: "Выполнено за всё время" и "Выполнено за сегодня"
* Поддержка **Google Chrome** и **Mozilla Firefox**
* Allure-отчеты для визуализации результатов

### API тесты:

* Создание и авторизация пользователей
* Ошибки при неверных данных или отсутствующих полях
* Создание заказов с авторизацией и без
* Проверка обязательных ингредиентов и корректности хешей


## ⚡ Инструкция по запуску

### 1. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Запуск всех тестов:

```bash
pytest -v
```

### 3. Запуск с Allure отчетом:

```bash
pytest --alluredir=allure-results
```

### 4. Просмотр Allure отчета:

```bash
allure serve allure-results
```
