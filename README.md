# 🌟 Stellar Burgers — Автотесты UI 🌟

**Проект:** Автотесты для UI
**Ветка разработки:** `develop3`

---

## 🎯 О проекте

Автоматизация UI-тестов веб-приложения **Stellar Burgers**:

* Проверка основной функциональности конструктора бургеров
* Работа с модальными окнами ингредиентов
* Drag & Drop ингредиентов в корзину
* Отслеживание счетчиков заказов в реальном времени
* Поддержка браузеров **Google Chrome** и **Mozilla Firefox**
* Генерация **Allure-отчёта** с подробной аналитикой

---

## ⚡ Быстрый старт

### 1️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2️⃣ Запуск всех тестов

```bash
pytest -v
```

### 3️⃣ Запуск с Allure-отчётом

```bash
pytest --alluredir=allure-results
```

### 4️⃣ Просмотр отчёта

```bash
allure serve allure-results
```

## 📂 Структура проекта

| 📁 Файл / Папка       | 🔹 Описание                                                                      |
| --------------------- | -------------------------------------------------------------------------------- |
| `test_constructor.py` | Проверка основной функциональности (конструктор, модалки, счетчики ингредиентов) |
| `test_order_feed.py`  | Раздел «Лента заказов» (счетчики, заказы в работе)                               |
| `pages/`              | Page Object Model для всех страниц                                               |
| `locators/`           | Селекторы элементов страниц                                                      |
| `conftest.py`         | Фикстуры: драйвер, авторизация, mock-функции                                     |
| `data.py`             | Тестовые данные и учетные записи                                                 |
| `logger.py`           | Логирование тестов                                                               |
| `urls.py`             | URL страниц приложения                                                           |

## 🛠 Тестируемая функциональность

### 🍔 Конструктор бургеров

* Переходы по клику на **«Конструктор»**
* Переходы по клику на **«Лента заказов»**
* Открытие/закрытие **модального окна ингредиента**
* Увеличение счетчика ингредиента при добавлении в заказ

### 📊 Лента заказов

* Увеличение счётчика **«Выполнено за всё время»**
* Увеличение счётчика **«Выполнено за сегодня»**
* Появление номера заказа в разделе **«В работе»**

## 🐞 Найденные баги

### 1️⃣ 🔒 Авторизация не работает

* **Приоритет:** Высокий
* **Описание:** После ввода корректных данных (`email: vasiliiandreev100500@yandex.ru`, `password: 123456`) авторизация не выполняется.
* **Проблемы:**

  * Остается на странице логина после нажатия **«Войти»**
  * **Access Token** не устанавливается в `localStorage`
  * Кнопка заказа: «Войти в аккаунт» вместо «Оформить заказ»
* **Шаги воспроизведения:** открыть главную страницу → кликнуть «Личный кабинет» → ввести email и пароль → нажать «Войти»
* **Ожидаемый результат:** Пользователь авторизован, токен установлен, кнопка «Оформить заказ»
* **Фактический результат:** Авторизация не происходит

---

### 2️⃣ 🖱 Drag & Drop не работает

* **Приоритет:** Высокий
* **Описание:** Перетаскивание ингредиентов в корзину конструктора не работает.
* **Проблемы:**

  * Ингредиенты не добавляются в корзину
  * Счетчик ингредиентов не увеличивается
* **Шаги воспроизведения:** открыть главную → перетащить ингредиент → проверить корзину
* **Ожидаемый результат:** Ингредиент добавлен, счетчик увеличен
* **Фактический результат:** Ингредиенты не добавляются

---

### 3️⃣ ❌ Невозможно оформить заказ

* **Приоритет:** Высокий
* **Описание:** После добавления ингредиентов и нажатия **«Оформить заказ»** модальное окно не появляется.
* **Шаги воспроизведения:** авторизоваться → добавить ингредиенты → нажать «Оформить заказ»
* **Ожидаемый результат:** Появляется модальное окно с номером заказа
* **Фактический результат:** Модальное окно не появляется
